# Foobs

A full-stack food management application built with Kotlin (Spring Boot/Jdbi) backend and an Angular frontend.

## 🔗 Live Demo
> **Check it out here:** [Foobs](https://foobs-app.onrender.com/)    
> *(Note: Free hosting may take a few seconds to "wake up" the server on the first load)*

## 🛠️ Tech Stack
- **Backend:** Kotlin / Spring Boot / Jdbi
- **Frontend:** Angular / TypeScript
- **Database:** PostgreSQL
- **Containerization:** Docker
